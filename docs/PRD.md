# 考研择校小程序 PRD v1.0

## 1. 项目背景与目标

考研报名人数持续高位运行，考生在择校阶段面临三大痛点：

1. **信息分散**：复试线、招生目录、复录比分散在研招网、各高校研究生院、各学院公告中，需逐站查询。
2. **决策缺乏依据**：仅看复试线无法判断竞争强度，缺乏"上岸真实分数"参考。
3. **择校盲目**：缺乏"冲/稳/保"的量化建议。

本产品对标「呱呱研选」，以微信小程序为载体，聚合公开招生信息，提供检索、复试线、招生目录、复录比统计、用户自报上岸分数及冲稳保推荐能力，辅助考生科学择校。

**北极星指标**：周活择校用户数 + 复试线查询完成率。

## 2. 对标分析

| 维度 | 呱呱研选（参考） | 本产品差异化 |
|------|------------------|--------------|
| 数据来源 | 公开招生信息聚合 | 同源，强调来源可溯源（每条记录带 source_url） |
| 复录比 | 提供 | 提供，并叠加"用户自报上岸分数"众数 |
| 冲稳保 | 推荐院校 | 提供透明算法 + 可调风险偏好（保守/平衡/激进） |
| 隐私 | 未知 | 用户填报默认匿名、不采姓名证件号 |
| 商业化 | VIP | VIP 控高级查询（深度复录比、导出、按分数段推荐） |

## 3. 目标用户与场景

- **主用户**：备考阶段（择校期 / 复试调剂期）的考研生。
- **次用户**：考研辅导机构、规划师（数据检索需求）。
- **核心场景**：
  1. 择校期：按地区/层次/学科筛院校，看历年复试线与复录比。
  2. 调剂期：按分数反向匹配可调剂院校。
  3. 出分后：填报上岸分数 + 看冲稳保建议。

## 5. 详细功能描述

### 5.1 院校专业检索（F1）
- 筛选条件：省份、院校层次（985/211/双一流/普通）、院校类型（综合/理工/师范…）、学科门类、专业名称模糊匹配。
- 结果列表：院校名、层次标签、开设的匹配专业数、近一年复试线摘要。
- 排序：默认综合，可按地区/层次/复试线。
- 索引：school_majors + 全文索引（专业名/学院名）。

### 5.2 历年复试线（F2）
- 展示某院校某专业近 3-5 年复试线（总分 + 单科）。
- 区分国家线 / 自划线 / 院线（type 字段）。
- 趋势折线图。
- 数据来源 PDF/官网 URL 可溯源。

### 5.3 招生目录（F3）
- 按年度展示：学院、专业、研究方向、初试科目、拟招生人数、推免占用、参考书目。
- 支持跨年度对比（人数变化）。

### 5.4 复录比统计（F4）
- 复试人数 / 录取人数 / 复录比 / 最高分 / 最低分 / 平均分。
- 免费看概览；VIP 看分方向明细 + 历年趋势。

### 5.5 用户上岸分数填报（F5）
- 字段：报考院校、专业、年份、总分、各科分数、生源类型（一志愿/调剂）、结果（录取/复试未录/未进复试）、本科层次（可选）、生源省份（可选）。
- **不采集**：姓名、身份证号、准考证号、手机号、邮箱。
- 默认匿名；登录用户可关联自己记录但不向他人展示身份。
- 提交需二次确认"自愿授权匿名用于统计"。

### 5.6 冲稳保算法（F6）
- 输入：用户分数 + 目标院校/专业（或全部）。
- 算法（透明、可解释）：
  - 取该院校专业近 3 年录取最低分 L 与平均分 A。
  - 冲：用户分 ≥ L-5 且 < A（成功率档 ~30%）。
  - 稳：A ≤ 用户分 < A+10（~60%）。
  - 保：用户分 ≥ 近 3 年最高录取分 -10（~85%）。
- 输出三类院校列表 + 命中依据（"近3年最低分 X，你的分数 Y"）。
- 风险偏好滑块：保守/平衡/激进调整阈值偏移量。

### 5.7 微信登录（F7）
- 小程序 `wx.login` → code → 后端 `code2session` 换 openid/session_key。
- 首次登录创建 user + 绑定 wechat_accounts。
- 颁发 JWT（access 2h + refresh 7d）。
- 手机号授权为可选，仅在 VIP 订单需要时采集（合规最小化）。

### 5.8 VIP 控制（F8）
- 中间件装饰高级查询路由（深度复录比、导出、按分数段推荐）。
- 校验 vip_memberships 有效期。
- 鉴权失败统一 403。
- 前端 VIP 标识 + 锁定态。

## 7. 业务流程

### 7.1 择校检索
打开小程序 → 首页检索入口 → 多条件筛选 → 结果列表 → 院校详情（复试线/招生目录/复录比 Tab）。

### 7.2 分数填报
个人中心 → "我的上岸记录" → 填写表单 → 二次确认授权 → 提交（待审核）→ 审核通过进入统计池。

### 7.3 冲稳保
输入分数 → 选院校/专业（或自动全量）→ 计算 → 三档列表 + 依据 → 点击跳详情。

## 8. 非功能需求

- **性能**：检索 P95 < 800ms（含 Redis 缓存命中）；详情 P95 < 1.2s。
- **可用性**：单实例 MVP，目标 99% 月可用。
- **合规**：仅聚合公开信息；用户数据脱敏；爬虫合规（见 CRAWLER_COMPLIANCE.md）。
- **安全**：JWT + 限流 + 参数化查询 + VIP 网关。
- **可观测**：结构化日志；crawl_logs / audit_logs 审计。
- **小程序合规**：HTTPS、备案、用户授权弹窗、隐私协议页。

## 9. 风险与约束

| 风险 | 影响 | 缓解 |
|------|------|------|
| 高校 PDF 结构差异大 | 解析失败率 | pdfplumber 表格抽取 + 人工复核 + 失败入 pdf_sources 待处理 |
| 数据时效性 | 复试线滞后 | 年度更新任务 + "数据更新于"标注 + 订阅通知 |
| 爬虫合规 | 法律风险 | 仅本地测试脚本 + 商业化前授权评估 |
| 用户填报造假 | 数据可信度 | 审核机制 + 异常值检测 + 仅作参考 |
| 小程序审核 | 上架受阻 | 隐私协议完备 + 不诱导分享 |
